### Fixed

- **An unreadable Trash is never shown as empty.** macOS lets only a process with Full Disk Access read the Trash, and never asks for it. Where the terminal lacks it, `trash list` used to print "Trash is empty". Now it says the Trash can't be read, why, and what grants it, and exits 1.
- **A trashed file whose origin couldn't be recorded says so,** with the command that still restores it.

### Added

- **trash.app reads the Trash for any terminal.** `trash` is now installed as an app: when macOS refuses your terminal the Trash, the same command runs again as trash.app, which holds Full Disk Access of its own. Give it once: open trash.app, and it shows you where. Installed with `brew install --cask adriangalilea/tap/trash`; the old formula is retired.
